What I build with.

No affiliate links, no endorsements — just the honest list of what's on my desk and in my terminal.

Hardware

One laptop, well-used. It runs the code, the browser tabs and the occasional game — which is exactly why everything I build stays light enough to run on machines like mine.

Editor & terminal

  • VS Code — plus vim keybindings, because at some point every developer gives in.
  • Windows Terminal — Python, Node and Git live here; half my workflow is muscle memory.
  • Git — small commits, honest messages. The history of each of my projects is basically a public dev log.

What actually taught me

  • CS50x — the foundations. C first, honestly, was a gift: you can't un-know how memory works.
  • CS50P & CS50W — Python habits, then the full web stack: SQL, Flask, JavaScript, deployment.
  • Shipping, constantly — every project above started as "can I even do this?" Five of them ended as live URLs. That loop — attempt, ship, learn — taught more than any course could.

On the desk

Tea (the drink that powers most of this portfolio), a notebook for the messy diagrams before code exists, and a second monitor that is more often a playlist than a terminal. Nobody's setup is as aesthetic as they pretend — this one at least ships software.
